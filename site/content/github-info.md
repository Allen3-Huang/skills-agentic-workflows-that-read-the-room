## Recent updates worth knowing

- **Copilot code review can approve pull requests.** Copilot's automated code review can now formally approve a PR, not just leave comments, streamlining review workflows. ([GitHub Changelog](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests))
- **GitHub CLI supports media uploads.** `gh` can now attach images and other media directly to issues, pull requests, and comments from the command line. ([GitHub Changelog](https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments))
- **Copilot code review effort levels are generally available.** Teams can tune how thorough Copilot's review passes are, balancing speed against depth. ([GitHub Changelog](https://github.blog/changelog/2026-08-07-copilot-code-review-effort-levels-are-generally-available))
