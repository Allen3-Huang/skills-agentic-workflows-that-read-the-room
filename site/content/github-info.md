## Recent updates worth watching

- **Copilot code review can now approve pull requests.** Copilot flags when a PR is ready to approve, and admins can turn on an option letting Copilot sign off itself (off by default). Source: [GitHub Changelog](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests/).
- **GitHub CLI can attach images and videos to issues, PRs, and comments.** A new repeatable `--attach` flag on `gh` uploads a local image or video and references it inline in the body. Source: [GitHub Changelog](https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments/).
- **GitHub Actions early-September updates.** New REST API for runner version deprecations, plus improvements giving clearer visibility and finer-grained control over workflows. Source: [GitHub Changelog](https://github.blog/changelog/2026-09-03-github-actions-early-september-2026-updates/).
