## Recent updates worth watching

- **Copilot code review effort levels are generally available** — reviewers can now tune how thorough Copilot's automated code review is per repository or pull request. ([GitHub Changelog](https://github.blog/changelog/2026-08-07-copilot-code-review-effort-levels-are-generally-available/))
- **Agent Plugins 1.0** now ship in VS Code, Copilot CLI, and the Copilot app, letting teams package reusable Copilot behaviors and share them across tools. ([GitHub Changelog](https://github.blog/changelog/2026-08-12-agent-plugins-1-0-in-vs-code-copilot-cli-and-the-copilot-app/))
- **Rule insights for organizations** (public preview) adds a dashboard showing allowed, failed, and bypassed repository ruleset evaluations, making it easier to audit branch protection at scale. ([GitHub Changelog](https://github.blog/changelog/2026-08-12-rule-insights-for-organizations-in-public-preview/))
- **Trigger Copilot automations with comments** — Copilot coding agent tasks can now be kicked off directly from issue and pull request comments, streamlining agent hand-off. ([GitHub Changelog](https://github.blog/changelog/2026-08-03-trigger-copilot-automations-with-comments/))
- **Agent apps** bring your software delivery workflow into GitHub, connecting external automation tools directly to issues and pull requests. ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/how-to-bring-your-software-delivery-workflow-into-github-with-agent-apps/))
