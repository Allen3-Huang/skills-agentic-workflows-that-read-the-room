## Recent updates worth watching

- **Copilot code review adds resolution reasons.** Reviewers can now tag why a Copilot code review comment was resolved, and the feature has expanded capabilities for triaging feedback faster. ([GitHub Changelog](https://github.blog/changelog/2026-08-27-copilot-code-review-resolution-reasons-and-expanded-capabilities/))
- **GitHub Copilot app gets a Customize tab (GA).** MCP servers, plugins, skills, and canvases are now managed together in one place inside the Copilot app. ([GitHub Changelog](https://github.blog/changelog/2026-08-25-github-copilot-app-customize-tab-is-generally-available/))
- **Copilot comes to Slack.** A new GitHub Copilot experience lets teams ask questions and trigger agentic work directly from Slack conversations. ([GitHub Changelog](https://github.blog/changelog/2026-08-21-the-new-github-copilot-experience-in-slack/))
- **From coder to orchestrator.** A GitHub Blog piece on how AI coding agents are reshaping the developer's role from writing every line to directing and reviewing agent work. ([GitHub Blog](https://github.blog/developer-skills/career-growth/from-coder-to-orchestrator-how-agents-shift-the-role-of-a-developer/))
