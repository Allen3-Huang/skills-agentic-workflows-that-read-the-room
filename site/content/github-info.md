## Recent updates worth knowing

- **Copilot CLI keeps expanding into chat apps.** GitHub Copilot's agentic work is now shareable in Microsoft Teams and Slack, so teams can hand off coding sessions without leaving their chat tool. ([GitHub Changelog: Shared agentic work with GitHub Copilot in Microsoft Teams](https://github.blog/changelog/2026-08-21-shared-agentic-work-with-github-copilot-in-microsoft-teams), [The new GitHub Copilot experience in Slack](https://github.blog/changelog/2026-08-21-the-new-github-copilot-experience-in-slack))
- **Copilot Code Review matured.** Effort levels are now generally available, and reviews can include resolution reasons and expanded capabilities—useful context when triaging automated review comments on a pull request. ([GitHub Changelog: Copilot code review effort levels are generally available](https://github.blog/changelog/2026-08-07-copilot-code-review-effort-levels-are-generally-available), [Copilot code review resolution reasons and expanded capabilities](https://github.blog/changelog/2026-08-27-copilot-code-review-resolution-reasons-and-expanded-capabilities))
- **Repository automation triggers got easier.** You can now kick off Copilot automations directly from an issue or pull request comment, cutting down on manual workflow dispatches. ([GitHub Changelog: Trigger Copilot automations with comments](https://github.blog/changelog/2026-08-03-trigger-copilot-automations-with-comments))
- **Rulesets keep replacing branch protection.** Branch protection rules can now be migrated automatically to repository rulesets, and new push rules support path exceptions—handy when locking down a repo without blocking legitimate merges. ([GitHub Changelog: Automatically migrate branch protection rules to repository rulesets](https://github.blog/changelog/2026-08-11-automatically-migrate-branch-protection-rules-to-repository-rulesets), [Push rules in rulesets now support path exceptions](https://github.blog/changelog/2026-08-25-push-rules-in-rulesets-now-support-path-exceptions))
