## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.

- Recent GitHub Blog and Changelog stories worth watching.

## Recent updates (August 2026)

- **Copilot code review adds resolution reasons.** Review comments can now be closed with a reason (e.g. "not relevant"), plus expanded review capabilities. ([GitHub Changelog](https://github.blog/changelog/2026-08-27-copilot-code-review-resolution-reasons-and-expanded-capabilities/))
- **Label archiving is generally available**, making it easier to retire unused labels without deleting their history. ([GitHub Changelog](https://github.blog/changelog/2026-08-27-label-archiving-is-generally-available/))
- **GitHub Copilot in VS Code (August releases, v1.132–v1.135)** improved agent session management: side-by-side chats, a `/btw` side-conversation command, a prompt timeline for navigating long chats, and portable agent plugins. ([GitHub Changelog](https://github.blog/changelog/2026-08-31-github-copilot-in-vs-code-august-2026-releases/))
- **GitHub Classroom is deprecated.** Educators should plan migration paths ahead of shutdown. ([GitHub Changelog](https://github.blog/changelog/2026-08-27-github-classroom-deprecated/))
